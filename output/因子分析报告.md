## 一、指标说明

### 1.1 IC（信息系数 / Information Coefficient）

因子值与下一期收益的截面Spearman相关系数。

| IC值 | 含义 |
|------|------|
| IC > 0 | 因子值越高 → 未来收益越高（正向因子） |
| IC < 0 | 因子值越低 → 未来收益越高（负向因子） |
| \|IC\| > 0.01 | 有实际预测意义 |
| \|IC\| > 0.03 | 预测力较强 |

### 1.2 IR（信息比 / Information Ratio）

IC均值 ÷ IC标准差。衡量因子预测的**稳定性**。

| IR值 | 稳定性 |
|------|--------|
| > 0.3 | 较稳定 |
| > 0.5 | 很稳定 |
| > 1.0 | 极其稳定（罕见） |

### 1.3 Sharpe（夏普比）

多空组合年化收益 ÷ 年化波动率。**风险调整后收益**。

| Sharpe | 评价 |
|--------|------|
| > 0.5 | 可接受 |
| > 1.0 | 优秀 |
| > 2.0 | 极其优秀 |

### 1.4 FM t-stat（Fama-MacBeth t统计量）

因子在截面回归中的t值。衡量因子溢价是否**统计显著**，不是随机噪音。

| \|t\| | 置信水平 | 含义 |
|------|---------|------|
| > 2.58 | 99% | ⭐ 高度显著 |
| > 1.96 | 95% | ✅ 统计显著 |
| > 1.0 | 85% | ⚠️ 弱显著 |
| < 1.0 | — | ❌ 不显著，可能只是噪音 |

### 1.5 多空年化收益

做多因子值最高组、做空最低组的年化收益差。

- **正值**：因子越大越好（做多高值组）
- **负值**：因子越小越好（做多低值组）
- 此策略的**空头端实际不可交易**（融券限制），真实收益约为多空的一半

### 1.6 IC正比例

IC为正的天数占比。判断因子方向是否**持续一致**。

- **> 55%**：方向较稳定
- **> 60%**：方向很稳定
- **< 50%**：方向不稳定，正负交替

## 四、买入建议

### 市场判断

本期A股（2023.06 → 2026.05）特征：
1. **反转效应主导** — 短期反转是唯一显著因子
2. **动量失效** — 过去涨的股票不会继续涨
3. **无明显风格** — 大小盘分化不显著
4. **高波动股需回避** — 暴涨股后续最差

### 策略：1周反转选股

**每周调仓，每周末执行以下步骤：**

```
① 计算每只股票过去5个交易日累计收益 = st_reversal_1w
② 将所有股票按 st_reversal_1w 从小到大排序（负值越大越好 = 跌得最多）
③ 选择排名前20%的股票（跌最多的20只）等权买入
④ 同时做空排名后20%的股票（涨最多的20只）—— 或仅做多低值组
⑤ 持有1周，下周一轮换
```

**风险提示**：
- 多空组合年化25.1%中，空头端约贡献一半收益，纯多头（仅做多反转股）预期年化约 **12-15%**
- 反转策略在**单边下跌市**中可能失效（跌的股票继续跌）
- 建议搭配低Beta股票降低组合波动
- 交易成本较高（每周全仓换手），实盘需控制滑点

### 应该避免

- ❌ **动量策略**：目前A股反转主导，追涨杀跌会亏钱
- ❌ **追高**：过去1个月涨幅最大的股票后续表现最差
- ❌ **高杠杆**：市场风格不明确，杠杆放大风险

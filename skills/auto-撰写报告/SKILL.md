# 因子分析最终报告撰写

挖掘和分析产出数据；这道门产出最终交付物。

本 skill 在流水线产出数据（CSV + JSON + 图表）的基础上，撰写**一份完整的、可交付的因子分析报告**。它不是简单地运行代码，而是逐模块组织证据、做出判定、形成结论。

## 输入源

| 数据来源 | 路径 | 用途 |
|---------|------|------|
| 因子检验汇总 | `output/ashare_factor_report.csv` | IC/IR/Sharpe/FM t 等核心指标 |
| 分析摘要 | `output/analysis_summary.json` | 总体评级、最佳因子 |
| 原始因子报告 | `output/factor_report.md` | 基础报告内容 |
| 因子数据 | `output/factor_data.parquet` | 截面相关性、子时期分析 |
| 图表 | `figures/*.pdf` | IC时序、累计收益、衰减、热力图 |
| 候选因子清单 | `paper_research/factor_ideas.md` | 文献预期方向 |
| 论文对比报告 | `paper_research/comparison_report.md` | A股 vs 论文偏差分析 |
| 共识矩阵 | `paper_research/consensus_matrix.md` | 跨方法共识 |
| 评估留痕 | `paper_research/final_recommendation.md` | 最终推荐因子清单 |

## 输出产物

| 文件 | 说明 | 优先级 |
|------|------|--------|
| `output/因子分析报告.md` | **主报告** — 8 模块完整版 | ★ 必须 |
| `output/factor_report.md` | 简洁版报告（无分析解读） | 可选 |
| `output/factor_report.html` | HTML 渲染版 | 可选 |

## 8 模块标准结构

每份报告按以下 8 个模块组织：

```
模块 1: 执行仪表盘          ← 一页看完所有关键结论
模块 2: 因子分类概览        ← 按类别/方向聚合
模块 3: 单因子深度分析      ← IC/IR/分组收益逐个解读
模块 4: 截面相关性          ← 因子重叠信息判断
模块 5: IC 衰减分析         ← 预测力持续时间
模块 6: 子时期稳健性        ← 牛/熊/震荡市分别表现
模块 7: 文献交叉验证        ← 论文预期 vs A 股实测
模块 8: 结论与行动          ← 买/不买/继续观察
```

### 模块 1: 执行仪表盘

简短精炼，一页覆盖：

```markdown
# 因子分析最终报告
> 分析期间: YYYY-MM-DD → YYYY-MM-DD
> 股票池: {数量} 只 A 股
> 因子总数: {数量} | 有效: {数量} | 可疑: {数量} | 无效: {数量}

## 核心发现

- **最佳因子**: {name} (IC={val}, FM t={val}, Sharpe={val})
- **主要信号**: 正向/负向，{方向解读}
- **整体质量**: {优秀/良好/一般/差}
- **文献一致性**: {与论文预期一致/部分偏差/方向相反}
- **建议**: {买入/继续观察/放弃}
```

### 模块 2: 因子分类概览

按因子类别分组展示，而非按显著性平铺：

| 类别 | 因子数 | 有效 | 最佳 IC | 平均 IR | 整体评级 |
|------|--------|------|---------|---------|---------|
| 风险类 | 4 | 2 | 0.032 | 0.12 | ⚠️ 弱 |
| 量价类 | 6 | 1 | -0.051 | -0.22 | ✅ 中 |
| 基本面 | — | — | — | — | 数据未覆盖 |

**关键观察**: 哪类因子在本期最有效，哪类整体失效。

### 模块 3: 单因子深度分析

对**每个因子**（逐个）做标准化分析：

```
## {因子名} ({中文名})

| 指标 | 数值 | 判定 |
|------|------|------|
| Mean_IC | {val} | ✅/\|IC\|>0.01 |
| IR | {val} | ⚠️ IR<0.3 |
| Sharpe | {val} | ❌ Sharpe<0 |
| FM t-stat | {val} | ✅ 显著/\|t\|>1.96 |
| 多空年化 | {val} | {解读} |
| IC 正比例 | {val} | {解读} |
| 综合评分 | {score} | {有效/可疑/无效} |
| 方向 | 正向/负向/不显著 | {交易含义} |

**解读**: {2-3 句话分析：IC 方向是否有经济含义、统计上是否可信、交易上是否可行}

{关联图表: IC 时序图、累计收益图}
```

## 撰写流程

### Step 0: 收集并验证输入数据

```bash
# 确保关键输入文件存在
BASE="/Users/zhangpeifu/Library/Mobile Documents/com~apple~CloudDocs/my all memory/factors"
INPUTS=(
  "$BASE/output/ashare_factor_report.csv"
  "$BASE/output/analysis_summary.json"
  "$BASE/paper_research/factor_ideas.md"
)
for f in "${INPUTS[@]}"; do
  [ -f "$f" ] && echo "✅ $f" || echo "❌ 缺失: $f"
done
```

### Step 1: 读取并理解数据

- 读取 `ashare_factor_report.csv` — 掌握所有因子的指标分布
- 读取 `analysis_summary.json` — 记录总体评价
- 读取 `paper_research/factor_ideas.md` — 获取文献预期方向
- 列出有效因子（FM t > 1.96）、弱显著因子（FM t > 1.0）、不显著因子（FM t < 1.0）

### Step 2: 按 8 模块逐步撰写

遵循**自顶向下**原则：
1. 先写 4~8 模块（细节分析），再回写 1~3（摘要和概览）
2. 每个模块写完问自己：**"这个模块的结论有数据支撑吗？"**
3. 当一个因子的文本从多个模块重复出现时，剪掉冗余，同一个结论只出现一次

### Step 3: 引用图表

在合适位置引用 `figures/` 下的图表：

```markdown
![IC 时序 - {因子名}](../figures/ic_series_{factor_name}.pdf)
*图: {因子名} 每日 IC 及 22 日滚动均值。{单句解读}*
```

引用规则：
- 模块 3（单因子分析）：引用 IC 时序图 + 累计收益图
- 模块 4（截面相关性）：引用热力图
- 模块 5（IC 衰减）：引用 IC 衰减图
- 模块 6（子时期）：引用仪表盘

### Step 4: 质量检查

逐项核查：

- [ ] 8 个模块齐全，无遗漏
- [ ] 每个因子都有判定结论（买入/观望/放弃）
- [ ] 每个数值都与 CSV/JSON 源数据一致（不编造数字）
- [ ] 图表引用正确，均有单句解读
- [ ] 文献对比结果明确标注方向一致性
- [ ] 买入策略包含选股标准、权重、调仓频率、风险提示
- [ ] 语言专业、简洁、无冗余
- [ ] 结论可追溯：每个"买入"都有 IC/FM t/Sharpe 支持

### Step 5: 输出

```bash
# 写入主报告
report_path="$BASE/output/因子分析报告.md"
# 报告内容已在上一步撰写完毕
echo "✅ 报告已写入: $report_path"
```

## 判定速查表

撰写报告时快速参考：

| 情景 | 报告中的表述 |
|------|------------|
| IC>0, FM t>1.96 | "正向因子，IC 为正且统计显著，因子值越高越好，做多高值组" |
| IC<0, FM t>1.96 | "负向因子，IC 为负且统计显著，因子值越低越好，做多低值组" |
| |t|>1.96 但 |IC|<0.01 | "统计显著但经济意义有限，IC 绝对值偏小" |
| IC>0.03, FM t<1.0 | "IC 方向有吸引力但统计不显著，需更多数据确认，暂不投入实盘" |
| 论文预期正、A股实测负 | "方向与文献相反，怀疑是 A 股市场微观结构差异所致（散户主导、T+1 交易）" |
| 子时期 IC 波动大 | "因子表现存在市场状态依赖，建议结合市场状态择时使用" |
| 多空收益>10%且 Sharpe>1 | "因子不仅统计显著，且扣除风险后仍具可观经济价值" |
